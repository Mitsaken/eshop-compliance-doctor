## Τι είναι το eShop Compliance Audit

Το **eShop Compliance Audit** (πρώην AccessCheck GR) είναι ένα 100% Local-First εργαλείο ελέγχου κανονιστικής τεκμηρίωσης για την ελληνική αγορά ηλεκτρονικού εμπορίου.

Βοηθά ιδιοκτήτες e-shops, web developers και agencies να ελέγχουν κείμενα **Όρων Χρήσης**, **Πολιτικής Επιστροφών** και **Πολιτικής Απορρήτου/Cookies** έναντι απαιτήσεων του Ν. 2251/1994, του Αστικού Κώδικα, του Γ.Ε.ΜΗ., του Ν. 5317/2026 (Άρθρο 3ζα) και της Οδηγίας EmpCo (ΕΕ) 2024/825, με ρητή επισήμανση ότι ο έλεγχος καλύπτει αποκλειστικά το υποβληθέν κείμενο.
